# 因果推断与商业应用

## Chapter 2 Causal Diagrams（因果图）

### 本章核心问题
如何用图形语言表示变量之间的因果关系？如何根据图形判断应该控制哪些变量、不应该控制哪些变量？

---

### 历史背景
- **Sewell Wright**：20 世纪初遗传学家，发展了用于因果推断的路径图（path diagrams）。
- **Phillip Wright**：Sewell Wright 的父亲，用这些图证明了工具变量（IV）估计量的存在。
- **Judea Pearl 与同事**：在 UCLA 人工智能领域发展了有向无环图（DAG）建模，形成了形式化的因果推断方法论。

---

### 有向无环图 DAG：基本定义

#### 图的构成
- **顶点（vertices / nodes）**：代表变量。
  - 实心圆：可观测变量。
  - 空心圆：不可观测变量。
- **边（edges / links）**：代表变量间的关系。
  - 有向边 `→`：起点变量导致终点变量。
  - 无向边 `—`：关系方向不确定。
  - 双向边 `↔`（虚线弯曲）：两个终端变量有共同的不可观测原因。
- **骨架（skeleton）**：去掉所有箭头后的无向图。

#### DAG 的要求
- 所有边都是有向的。
- 不能包含**有向环**（directed cycle），例如 X→Y 且 Y→X。但可以有互相因果的反馈过程，只是不在同一个 DAG 中表示。
- 每个 DAG 至少有一个 **root（没有父节点的节点）** 和一个 **sink（没有子节点的节点）**。

#### 路径相关术语
- **Path（路径）**：一系列边的序列，不考虑箭头方向。
- **Directed path（有向路径）**：所有箭头方向一致的路径。
- **Back-door path（后门路径）**：从原因变量 D 到结果变量 Y 的路径，且路径以指向 D 的箭头开始、以指向 Y 的箭头结束。即路径上第一个箭头是 "...→D"，最后一个箭头是 "...→Y"。
- **Adjacent（相邻）**：两个顶点之间有边直接相连。
- **Connected（连通）**：两个顶点之间存在路径。
- **Kinship 术语**：Parents（父节点）、Children（子节点）、Ancestors（祖先）、Descendants（后代）、Spouses（配偶节点，通过双向边相连）。

### 因果关系的三种基本模式

图形中的信息流有三种基本结构，它们决定了两个变量之间是否“自然”相关，以及控制某个变量后会发生什么。

#### 1. Chain（链 / 因果路径）
结构：A → C → B
- C 是 A 对 B 影响的**中介变量（mediator）**。
- A 和 B 相关，因为 A 通过 C 影响 B。
- **控制 C 会阻断 A 和 B 之间的关联**。

**经典例子：柑橘 → 维生素 C → 坏血病**
- Citrus fruits → Vitamin C → Scurvy
- 吃柑橘能预防坏血病，并不是因为柑橘本身有什么神奇成分，而是因为它提供了维生素 C。
- 如果我们在回归中同时放入“柑橘摄入”和“血液中维生素 C 含量”，后者的系数会吸收掉大部分中介效应，导致前者系数变得不显著。

**直观理解**：
链就像一条河流。A 是上游，B 是下游，C 是中间的一段河道。如果不控制 C，我们看到 A 和 B 有关联；但如果把水闸设在 C 处截断，A 就无法影响 B 了。

---

#### 2. Fork（叉 / 混杂路径）
结构：A ← C → B
- C 是 A 和 B 的**共同原因（common cause）**，即混杂因子（confounder）。
- A 和 B 相关，但不是因为 A 导致 B 或 B 导致 A，而是因为它们共同受 C 影响。
- **控制 C 会阻断 A 和 B 之间的虚假关联**。

**经典例子 1：冰淇淋销量与溺亡人数**
- Temperature → Sales of ice cream
- Temperature → Drowning deaths
- 冰淇淋销量和溺亡人数高度相关，但吃冰淇淋并不会导致溺亡。高温是混杂因子。

**经典例子 2：教育与收入**
- Ability → Education
- Ability → Income
- 教育和收入相关，部分是因为能力同时影响两者。如果不控制能力，会高估教育的真实回报。

**直观理解**：
叉就像一个分叉的水管。C 是水龙头，A 和 B 是两条出水口。关掉水龙头（控制 C），两条出水口之间就没有水流关系了。

---

#### 3. Inverted Fork / Collider（倒叉 / 对撞路径）
结构：A → C ← B
- C 是 A 和 B 的**共同结果（common effect）**，称为**对撞因子（collider）**。
- 在没有控制 C 时，A 和 B 是**独立的**（假设它们原本没有直接关系）。
- **控制 C 会在 A 和 B 之间制造虚假的负相关或正相关**。

**经典例子 1：才华与美貌 → 名人身份**
- Talent → Celebrity ← Beauty
- 才华和美貌之间原本可能没有相关性。
- 但如果我们只看“名人”这个子群体（即控制了 Celebrity 或其 descendant），会发现才华高的人可能美貌一般，美貌高的人可能才华一般——因为在名人选拔中，两者可以互相替代。

**经典例子 2：SAT 成绩与入学动机 → 大学录取**
- SAT score → College admission ← Motivation
- 假设大学录取完全由 SAT 和面试动机评分决定，且两者原本独立。
- 在被录取的学生中，SAT 高的人往往动机评分低，动机评分高的人 SAT 可能较低——因为只要总分够高就能被录取。
- 这就是** Berkson's paradox / collider bias**。

**直观理解**：
对撞就像一个漏斗。A 和 B 是两股独立的水流，C 是漏斗口。如果我们只观察“成功通过漏斗的水”（控制 C），会发现 A 和 B 此消彼长——不是因为它们本身相关，而是因为漏斗的筛选机制。

### d-Separation（d-分离）准则

#### 定义
考虑三个不相交的变量集合 X、Y、Z。一条路径 p 被 Z **d-分离（阻断）**，当且仅当：
1. 路径 p 包含一个链 A → m → B 或叉 A ← m → B，且中间节点 m ∈ Z；或者
2. 路径 p 包含一个倒叉 A → m ← B（对撞），且中间节点 m ∉ Z，同时 m 的任何后代也不在 Z 中。

如果 Z 阻断了 X 和 Y 之间的每一条路径，则称 Z **d-分离** X 和 Y。

#### 核心直觉
- **链和叉**：控制中间节点会阻断信息流动。
- **对撞**：控制中间节点或其后代会打开信息流动。

#### 例子说明
**链**：A → C → B
- 不控制 C：A 和 B 相关。
- 控制 C：A 和 B 独立（被 d-分离）。

**叉**：A ← C → B
- 不控制 C：A 和 B 相关。
- 控制 C：A 和 B 独立。

**倒叉**：A → C ← B
- 不控制 C 及其后代：A 和 B 独立。
- 控制 C 或其某个后代：A 和 B 变得相关。

---

### 估计因果效应的三种基本策略

#### 策略一：阻断所有后门路径（Back-door blocking）
通过分层、匹配、加权或回归等方法，控制一组变量 Z，使得从原因变量 D 到结果变量 Y 的所有后门路径都被阻断。

**例子**：
```
A → F → Y
D → A ← B
D → Y
```
从 D 到 Y 的后门路径有：
1. D → A → F → Y
2. D → B → A → F → Y

控制 {A, B} 或 {F} 都可以阻断所有后门路径。

**为什么不能控制 collider？**
如果 A 同时是某个对撞结构的中间节点，控制 A 会打开新的路径，造成更多偏误。

---

#### 策略二：工具变量（Instrumental Variable）
寻找一个外生变量 Z，它只通过影响 D 来影响 Y，与 Y 没有直接关系，也不受混杂因子影响。

**例子**：
```
    C
    ↓
A → F → Y
↑
B → D
```
如果 C 是 D 的有效工具变量，则 C 只能通过 D 影响 Y。

---

#### 策略三：前门准则 / 机制识别（Front-door / Mechanism-based）
当后门路径无法阻断时（例如存在无法观测的混杂因子 U），可以找到 D 影响 Y 的完整中介机制 M，M 完全由 D 决定，且 M 到 Y 的后门路径可以被控制。

**例子**：
```
D → M → Y
↑     ↑
U ────┘
```
虽然 D ← U → Y 的后门路径因 U 不可观测而无法阻断，但如果 M 是 D 影响 Y 的孤立且穷尽机制，我们可以通过估计 D→M 和 M→Y 两个效应来识别 D→Y 的总效应。

---

### Back-Door Criterion（后门准则）

#### 定义
一组变量 Z 满足关于 (D, Y) 的后门准则，如果：
1. Z 不包含 D 的任何后代；
2. Z 阻断了 D 和 Y 之间的所有后门路径。

如果 Z 满足后门准则，则因果效应可以通过控制 Z 来识别：
$$
P(Y|do(D=d)) = \sum_z P(Y|D=d, Z=z) P(Z=z)
$$

#### 直观解释
后门路径是混淆因果解释的“后门”。我们要把后门都关上，但不能关上会把新鲜空气也挡住的门（控制 collider），也不能打开新的窗户（控制 descendant 打开对撞）。

#### 例子：教育、能力与工资
```
D (Education) → Y (Income)
      ↑              ↑
      └──── C (Ability) ┘
```
从 D 到 Y 的后门路径：D ← C → Y。
- 控制 C（能力）即可识别教育的真实效应。
- 如果不控制 C，观察到的教育与收入关联 = 教育真实效应 + 能力带来的共同依赖。

#### 计算步骤
1. 对每个 C=c 的子群体，计算 D 与 Y 的关联。
2. 按 C 的边际分布加权平均这些子群体关联。
3. 得到的加权平均就是 Pearl 框架下的因果效应，也即反事实文献中的平均处理效应（ATE）。

### Front-Door Criterion（前门准则）

#### 经典例子：吸烟与肺癌
历史上争论：吸烟是否导致肺癌？
- 可能存在不可观测的基因 Smoking gene 同时影响吸烟倾向和患癌风险。
- 后门路径 Smoking ← Gene → Lung Cancer 无法阻断。

Pearl 提出前门准则：
```
Smoking → Tar deposit → Lung cancer
    ↑                       ↑
    └────── Smoking gene ───┘
```
虽然基因不可观测，但我们可以：
1. 估计吸烟对肺部焦油沉积（Tar deposit）的因果效应。
2. 估计焦油沉积对肺癌的因果效应。
3. 将两者相乘，得到吸烟对肺癌的总效应。

#### 前门准则的条件
一个中介变量 M 满足前门准则，如果：
1. M 拦截了所有从 D 到 Y 的有向路径；
2. 从 D 到 M 的所有后门路径都被阻断（通常因为 D 是 M 的唯一原因）；
3. 从 M 到 Y 的所有后门路径都被 D 阻断。

#### 证明思路
$$
\begin{aligned}
P(Y|do(D=d))
&= \sum_m P(Y|do(M=m)) P(M=m|do(D=d)) \\
&= \sum_m \left[ \sum_{d'} P(Y|D=d', M=m) P(D=d') \right] P(M=m|D=d)
\end{aligned}
$$

- 第一步：利用 M 的中介作用，总效应 = D→M 的效应 × M→Y 的效应。
- 第二步：D→M 的效应可由 P(M|D) 直接估计，因为 D 到 M 没有后门路径。
- 第三步：M→Y 的因果效应可通过后门准则，控制 D 来识别。

**关键直觉**：
前门准则就像“借道而行”。正门（后门路径）被不可观测的基因堵死了，但我们可以通过测量中间机制 M，绕道识别总效应。

### 机制解释（Mechanism-based Explanation）

#### 完整机制的两个要求
1. **Isolation（隔离性）**：机制的各个组成部分不受不可控后门路径上变量的直接影响。
2. **Exhaustiveness（穷尽性）**：机制完整解释了 D 如何影响 Y，没有遗漏其他重要因果路径。

#### 反例 1：机制不孤立
```
    U
    ↓
D → M → Y
```
如果 U 同时影响 M 和 Y，则 M 不是孤立的。后门路径 M ← U → Y 无法被阻断，D 对 Y 的效应仍然混淆。

#### 反例 2：机制不穷尽
```
D → M → Y
  ↘ N ↗
```
如果还存在另一条未观测路径 D → N → Y，只估计 D→M→Y 会低估总因果效应。

#### 放宽穷尽性
如果只关心部分效应，可以放宽穷尽性，但必须假设观测到的机制部分与未观测的机制部分完全分离，不能互相作用。

---

### DAG 的优点与局限

#### 优点
1. 能够清晰展示因果模型中的关键假设。
2. do-演算可以系统化地回答特定因果查询。
3. 帮助我们判断应该控制哪些变量、不应该控制哪些变量。

#### 局限
1. 文献中缺乏具体的实证应用和令人信服的案例。
2. DAG 难以编码单调性（monotonicity）等形状限制。
3. 工具变量设定中的某些关键假设在 DAG 中不容易自然表达，而在潜在结果（PO）框架中更直接。
4. DAG 的优势在变量很多、结构复杂的模型中最明显，但这类模型在实证经济学中并不常见。

### 本章关键结论与证明

#### 结论 1：在 Chain A→C→B 中，控制 C 阻断 A 与 B 的关联
**证明**：
由条件独立性：
$$
P(B|A, C) = P(B|C)
$$
因此：
$$
P(B|A) = \sum_c P(B|C=c) P(C=c|A)
$$
若进一步有 P(B|A) = P(B)，则 A 和 B 独立。一般来说，A 通过 C 影响 B，控制 C 后 A 不再提供关于 B 的额外信息。

---

#### 结论 2：在 Fork A←C→B 中，控制 C 阻断 A 与 B 的关联
**证明**：
在 DAG 中，C 是 A 和 B 的共同原因。给定 C 后：
$$
P(A, B | C) = P(A|C) P(B|C)
$$
即 A 和 B 条件独立。因此控制 C 可以消除它们之间的虚假关联。

---

#### 结论 3：在 Collider A→C←B 中，控制 C 会打开 A 与 B 的关联
**证明**：
假设 A 和 B 独立：P(A, B) = P(A)P(B)。
但给定 C 后：
$$
P(A, B | C) = \frac{P(C|A, B) P(A) P(B)}{P(C)}
$$
由于 P(C|A, B) 依赖于 A 和 B 的组合，一般情况下 P(A, B | C) ≠ P(A|C)P(B|C)。
因此 A 和 B 在给定 C 后变得相关。

**例子**：SAT 与 Motivation
- 假设 SAT ~ N(0,1)，Motivation ~ N(0,1)，两者独立。
- 录取规则：Admitted = 1 当且仅当 SAT + Motivation > c。
- 在被录取者中，SAT 高的人 Motivation 可以较低，反之亦然，因此两者负相关。

---

#### 结论 4：Back-Door Criterion 识别因果效应
**证明概要**：
后门准则保证控制 Z 后，D 与潜在结果 Y(d) 独立：
$$
Y(d) \perp D | Z
$$
因此：
$$
\begin{aligned}
P(Y|do(D=d))
&= \sum_z P(Y|do(D=d), Z=z) P(Z=z) \\
&= \sum_z P(Y(d)|D=d, Z=z) P(Z=z) \\
&= \sum_z P(Y|D=d, Z=z) P(Z=z)
\end{aligned}
$$
第三步成立是因为 Y(d) 与 D 在给定 Z 后独立。

---

#### 结论 5：Front-Door Criterion 识别因果效应
**证明概要**：
设 M 满足前门准则，则：
$$
P(Y|do(D=d)) = \sum_m P(M=m|D=d) P(Y|do(M=m))
$$
其中 P(M=m|D=d) 可直接从数据估计（D→M 无后门路径）。

对于 P(Y|do(M=m))，由于 D 阻断了 M 到 Y 的所有后门路径：
$$
P(Y|do(M=m)) = \sum_d P(Y|M=m, D=d) P(D=d)
$$
因此：
$$
P(Y|do(D=d)) = \sum_m P(M=m|D=d) \sum_{d'} P(Y|M=m, D=d') P(D=d')
$$

---

### Key Takeaways
1. DAG 用有向无环图形式化地表示变量间的因果关系。
2. 三种基本路径结构：Chain（链）、Fork（叉）、Collider（对撞）。
3. 控制中间节点在 Chain 和 Fork 中阻断关联，但在 Collider 中打开关联。
4. d-Separation 是判断变量间条件独立性的图形准则。
5. 识别因果效应的三类策略：阻断后门路径、工具变量、前门准则 / 机制识别。
6. 后门准则要求控制所有后门路径，且不能控制 collider 及其后代。
7. 前门准则适用于存在不可观测混杂因子但有完整中介机制的情形。
8. DAG 能清晰表达假设，但在处理单调性、亚群体识别和某些 IV 假设时有局限。
